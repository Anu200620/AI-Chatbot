# 🤖 AI Chat Assistant

A simple and interactive web-based AI Chatbot built using HTML, CSS, and JavaScript — with a modern glassmorphism UI and smooth animations.

## 📌 About the Project

AI Chat Assistant is a lightweight, beginner-friendly chatbot web app. Users can chat with the bot and get automated responses for greetings, time, date, help, and goodbye — all handled with simple JS logic, no backend required.

## ✨ Features

- 💬 Interactive chat interface
- 🤖 Automated chatbot responses
- 👋 Greeting responses
- 🕐 Current time response
- 📅 Current date response
- ❓ Help response
- 👋 Goodbye response
- ⌨️ Enter key support
- 🎨 Modern glassmorphism design
- ✨ Smooth message animations
- 📱 Fully responsive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
